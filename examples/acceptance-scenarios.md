# 验收场景

前八类技术行为由离线测试覆盖。视觉行为需要真实原图与成品验证，不能由提示词检查证明。

| 输入或环境 | 应发生什么 |
| --- | --- |
| 视觉输入、有参考编辑、有结果视觉 | 选择 image-edit 计划，但离线脚本仍写 not-executed、生成数为 0 |
| 视觉输入、没有参考编辑 | Prompt Studio，完整英文提示词，不调用随机文字生图代替本人 |
| 只有文字输入 | 标记 text-template，不编造可见身份特征 |
| 附件缺失 | needs-reference，请用户提供照片 |
| 能看图但尚未看过本次原图 | awaiting-source-review，初始调用数为 0 |
| 没有目标服务的照片处理授权 | awaiting-provider-authorization，不规划外部调用 |
| 编辑结果无法查看 | image-edit-unreviewed，不能标为视觉质检通过 |
| 用户预算为一到五次 | 初始调用 + 修复调用不超过预算，修复不超过两次 |
| Finance 请求保留本人年龄、不打领带 | 不增加年龄、不强加领带；风格只影响摄影与服装 |
| 原图左右眼自然不同 | 保留差异，不以强制对称化“修复” |
| 原图闭嘴、无可见牙齿 | 不凭空发明宽露齿笑容 |
| 候选明显不像本人 | 拒绝推荐，回到原图或请求更清楚的照片 |
| 用户要上传 LinkedIn | 交付成品供本人终审；发布账号头像另需明确授权 |
| 要求护照/签证合规 | 说明该风格不提供官方证件合规，另查具体官方规范 |

未来加入真实图片回归集前，须另行取得保存和测试授权，并单独管理；不得把用户照片当作仓库测试素材。
