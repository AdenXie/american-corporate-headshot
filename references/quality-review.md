# 视觉质量审查

先比较原图与成品，再检查局部。检查状态使用 `pass`、`repair`、`fail` 或 `unknown`，每项附一句可见证据。没有看图时所有视觉判断都是 `unknown`，不能用数值总分替代审查，也不能声称通过率或零瑕疵。

## 一票停止的问题

- 人物明显变成另一个人，或脸部轮廓、眉眼间距、鼻唇、发际线显著漂移。
- 原图太模糊、遮挡或美颜严重，无法判断相似度。
- 关键区域不可见或结果无法打开，仍声称已完成视觉质检。

身份漂移优先回到原图；不要通过反复美化候选让陌生面孔变得更精致。本人终审优先于模型的相似度判断，这里不做实名验证，也不计算生物识别分数。

## 检查表

| 项目 | 检查方法 | 需要修复的例子 |
| --- | --- | --- |
| 身份 | 原图与成品并排，比轮廓、间距、鼻唇、下颌、发际线、标记和眼镜 | 换脸感、瘦脸、大眼、肤色或年龄被改动 |
| 眼睛 | 看瞳孔、视线、眼皮、镜片和反光 | 瞳孔重复、视线明显不一致、眼镜腿融进皮肤 |
| 自然差异 | 保留原图已有的左右差异 | 将真实大小眼或不对称笑容当瑕疵强行矫正 |
| 嘴唇与牙齿 | 比较原图可见程度，放大检查边缘 | 牙齿重复或粘连、唇线断裂、闭嘴原图被编成夸张露齿笑 |
| 耳朵、头发、颈部 | 检查与面部连接、发丝边缘和颈肩比例 | 耳廓畸形、缺失发际线、头颈融合、背景色光晕 |
| 皮肤 | 查看原尺寸或足够分辨率的脸部区域 | 蜡像磨皮、过锐毛孔、色块、虚假均匀质感 |
| 服装 | 查看肩线、双侧翻领、衣领、纽扣、领带和接缝 | 翻领融化、领带断裂、透视或布料受力不合理 |
| 光线 | 检查眼睛可读性、鼻影、肤色、高光和背景方向 | 面部曝光丢失、眼窝全黑、阴影方向矛盾 |
| 背景 | 看轮廓边缘与简洁程度 | 杂物、虚构公司标志、廉价布景、发丝抠图边缘 |
| 构图 | 原方图与居中圆形预览对照 | 头发、耳朵或下巴被裁掉，肩颈比例不自然 |
| 缩略效果 | 在宿主支持时实际查看约 96 px 圆形预览 | 脸太小、表情不清、眼镜或边缘问题更明显 |

约 96 px、方形 1024 px 是本项目的工作建议，不是 LinkedIn 或招聘平台的官方上传规格。需要平台合规时查当时的官方要求。未制作圆形预览时写“尚未验证圆形裁切”，不能凭提示词声称验证完成。

## 修复决策

局部缺陷且身份可靠：只修复一处或紧密相关的一组缺陷，原图继续作为身份依据。服装缺陷尽量局部编辑，不重画整张脸。无法局部编辑时，说明重生成会增加身份漂移风险，并再次比对。

身份漂移、牙齿不可知、耳朵被遮挡：优先换清楚的参考图或保持原有表情/遮挡方式。不得把不确定细节编成“合格”。最多两次修复后按预算停止。
