# 工具适配：先验证能力，再选流程

本 Skill 的工具适配层是“能力记录 + 调用契约”，不是后台服务或通用图片 API 客户端。各宿主负责把契约映射到已安装工具的真实接口。`scripts/prompt_studio.py` 只负责组装提示词、选择流程和给出预算，完全离线。

## 能力记录

在每次运行开始检查工具清单和文档，记录：

| 字段 | 为 true 的依据 |
| --- | --- |
| `inspect_inputs` | 视觉模型能实际访问并查看用户参考图；仅有 URL 或路径字符串不算 |
| `reference_edit` | 当前有可调用的工具，其文档明确支持把参考照片作为图像编辑输入 |
| `inspect_outputs` | 返回图片可由视觉模型打开查看；只返回无法访问的链接不算 |
| `tool` | 真实工具名称；没有编辑工具时为 null |
| `evidence` | 简短说明查阅的工具文档、接口版本或已验证的能力；不含密钥和图片内容 |

未知能力按 false 处理。`source_reviewed` 是本次任务的事实，不能由能力自动推出。身份保留是优先选择条件和质检要求，不是工具自称支持就能保证的结果。无法确定是否支持参考编辑时，先交付 Prompt Studio，不发送本人照片做探索性调用。

`examples/capabilities/` 是演示数据，不是自动探测器。使用者必须替换其中的工具名称和证据，不得将示例文件作为工具实际存在的证明。

## 统一调用契约

这是宿主实现约定，字段不直接发送给提供者：

```text
EditRequest
  original_identity_refs: 当前用户授权、可访问的本人原图
  candidate_to_repair: 可选，待修复候选图，不能取代原图
  prompt: 完整英文图像编辑提示词
  negative_constraints: 可选独立字段；无对应参数时已并入 prompt
  output_intent: 一张方形头肩照片，建议 1024×1024，工具支持时采用

EditResult
  artifact: 真实图片附件、可访问路径或宿主允许使用的结果链接
  actual_size: 实际能读取时记录，否则 unknown
  provider_or_tool: 实际调用对象
  inspection: pending / reviewed / unavailable
  error: 若失败，记录不含照片或秘密的错误摘要
```

工具没有独立 negative prompt、seed、参考强度或尺寸参数时，不虚构这些参数。尺寸只作提示词目标，不能宣称实际已满足。不同工具的参考图数量、格式、文件大小和身份控制机制以当前文档为准，不把某个模型的参数写成跨模型标准。

## 常见环境的接法

### 原生图片工具的聊天环境

1. 使用宿主查看附件的能力，先看原图。
2. 读取当前图片工具的编辑说明；原图通过真实附件引用、文件路径或受支持的最近图片机制传入。
3. 如果使用 OpenAI 的 `image_gen` 类工具，遵守该工具当次提供的参数与引用规则；不要把本仓库的抽象字段直接传给它。`imagegen` skill 可用时也应读取其编辑要求。本仓库不依赖它才能运行 Prompt Studio。
4. 每次收到图片后再查看并记录质检；工具若规定回复形式，优先遵守其要求，必要说明保留在工具调用前或允许的报告文件中。

### MCP、插件或 API 图片服务

由视觉模型读取用户参考图和图像服务文档，把契约映射到真实编辑工具。验证图片输出是否能回传视觉模型，而非只返回任务 ID。只使用宿主已经提供或用户授权配置的凭据，不扫描电脑找密钥。

提交异步任务算一次图像调用；使用只读查询查看同一任务进度不算新图像调用，但遵守服务轮询规则。下载或上传照片、变更服务商与付费任务均应符合用户已有授权范围。重试提交失败任务也消耗调用预算，避免重复收费。

### 视觉输入、文本输出模型

模型负责原图分析、选风格、组装提示词。用户或另一个已授权的图像编辑服务负责产出图片。用户把成品带回后，视觉模型才可检查。不要写“已生成三张”或“所有检查通过”。

### 纯文本环境

没有视觉输入时，`text-template` 只是通用模板。不能填入臆测的脸型、年龄、牙齿或其他可见特征。请求用户转到能看图的环境，不把用户文字描述当作已经看过照片。

## 预算与停止条件

初始候选默认三张，两张所选风格、一张相邻风格。可按用户偏好减为一张。全任务最多三次初始调用、两次修复调用，总数最多五次；用户给出更小预算时从其限制。当前生成器为每次调用规划一张图片，避免不同提供者批量机制的歧义。

停止条件包括：身份漂移无法可靠修复、参考图不足、返回图片不可查看且用户未同意接受未审查草稿、持续错误、服务额度/授权不足或预算耗尽。保留原图，不无限重试，不用另一个人的脸凑齐候选。用户主动要求继续时，说明已用预算和待修问题，再采用新的明确预算。

## 状态要如实报告

`image-edit` 只表示具备执行条件；离线脚本始终输出 `execution: not-executed`。宿主实际成功调用后才可以报告图片已生成，实际查看后才可以报告视觉质检。

脚本无法验证调用者提交的 `source_reviewed` 或授权声明，不能充当权限系统。宿主必须依据真实对话和工具输出填值。它也不执行 EXIF 清理、圆形裁切或图片上传。
